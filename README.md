# Factorisation Quest · Grade 8 Maths

Same architecture, UI/UX and audio pipeline as the Circumference module — new content.

## Run
```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build -> dist/
```

## Voice / audio (ElevenLabs "Alice", eleven_multilingual_v2)
The API key is already in `.env.local` (`VITE_ELEVENLABS_API_KEY`).

```bash
npm run audio          # generate any missing mp3s -> public/assets/audio/ and rewrite src/audioMap.js
node scripts/generate_audio.js --force   # regenerate everything
npm run audio:clean    # delete orphaned mp3s
```
Playback order in the app: pre-generated mp3 -> live ElevenLabs request (same per-style voice settings) -> browser speech synthesis.
Only paragraph text and questions are narrated (never titles).

To change a spoken line: edit the `phrases` array in `scripts/generate_audio.js`, run `npm run audio`, and keep the on-screen text in sync.

## Story images
`public/assets/images/slide1..8.svg` are generated by `node scripts/make_story_images.mjs`. Drop in your own PNG/SVG with the same names (and update the `image` paths in `src/stages/StoryPhase.jsx` if you change the extension).
